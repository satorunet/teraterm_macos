# Tera Term Mac のマクロ (TTL) 互換性メモ

Windows 版 Tera Term のマクロを、そのまま Tera Term Mac で動かすためのメモです。
どこを本家に合わせたか、どこを Mac 向けに変えたかをまとめています。

## 方針

| 種類 | どうしたか |
|---|---|
| マクロ言語としての動き (文法・式・変数・制御構文、命令の引数、`result` の値、エラー文、`wait` などが受け取る文字、送る文字、ログ、接続) | **本家に合わせる** |
| OS によって違うところ (パス、ファイルの共有ロック、ワイルドカードの細かい規則、Windows だけの設定・メニュー・キーコードの中身、タイムゾーン名、時計の変更) | **Mac (Apple) のやり方に従う** |

元にしたのは本家の `teraterm/ttpmacro` (マクロ)、`teraterm/ttpfile` (ファイル転送)、`teraterm/teraterm` (端末側) のソースです。

---

## 1. 本家のソースをそのまま使っているところ

本家のソースを使っているので、動きは Windows 版と同じです。

- **ファイル転送のプロトコル**: XMODEM / YMODEM / ZMODEM / Kermit / B-Plus / Quick-VAN と、`recvfile` の raw 受信
  - 本家の `ttpfile/*.c` を、手を加えずにそのまま組み込んでいる (`Sources/CTeraFile/ttpfile`)
- **正規表現**: 本家と同じ鬼車 (Oniguruma 6.9.10)
  - 使う命令: `waitregex` `strmatch` `strreplace` `regexoption`、`sprintf` の書式チェック
  - 既定の設定も本家と同じ (UTF-8・Ruby 文法・オプションなし)

## 2. 本家を移植して同じ動きにしたところ

Swift で書き直し、本家と同じ動きにしたところです。

### 文法と実行

- 字句解析
  - 文字列: `'…'` `"…"` `#13` `#$0d`、最大 511 バイト
  - 数: 10 進と `$` で始まる 16 進
  - 識別子: 31 文字まで、大文字小文字を区別しない
  - コメント: `;` と `/* */`
- 演算子: 優先順位、32 ビットの桁あふれ、シフト (`>>>` を含む)、0 での割り算のエラー、型チェック
- 予約語: 216 語すべて (番号まで機械的に照合済み)
- 変数と配列
  - システム変数とその初期値
  - `param1` と `params[1]` には、本家と同じくファイル名だけが入る
- 実行の流れ
  - ラベル、`include` (入れ子 9 段)、`call` と `return` のスタック (10 段)
  - if / elseif / else、while / until、for / next、do / loop、break / continue の、読み飛ばしの細かいくせまで本家と同じ
- エラー
  - エラー文と、エラーの出る行は本家と同じ
  - エラーのあと「続ける」を選んだときの動きも本家と同じ
  - 起動時のラベルの二重定義は、本家と同じくエラーを出してからマクロを続ける
- マクロファイルの文字コード
  - BOM (UTF-8 / UTF-16) を見る
  - NUL より後ろは読まない
  - 読めないファイルは「Can't open file.」

### 受信の待ち受け

- `wait` などが受け取る文字は、本家と同じく次のとおり
  - 画面に出した文字が UTF-8 で入る
  - 改行はログと同じ規則でそろえる。単独の CR は捨てる
  - TAB と NUL は入る
  - BS は、カーソルが動いたときだけ入る (既定の設定では入らない)
  - エスケープシーケンスは入らない
  - ESC D / ESC E は LF として入る
- 照合の規則
  - `wait` `waitln` `recvln` `waitregex` `waitrecv` `waitn` `wait4all` の照合
  - 時間切れのとき・切断したときの `result` と `inputstr`
  - `timeout` の 32 ビット計算
- `wait4all`: マクロが動いているウインドウ全部でそろうまで待つ
- `waitevent`: 状態が変わったときに起きる
- 空の文字列の `wait`: 次の 1 文字で一致する

### 命令

- **送信**
  - `send`: 文字として送るかバイナリとして送るかの判定は本家と同じ
  - 1 回に送るのは 511 バイトまで
  - CR は、送信の改行コードの設定に従って変換する
  - 切断中に送っても、自動で再接続しない
- **接続**
  - `connect` のパラメータは Tera Term のコマンドラインと同じ書式
    - `"…"` でくくれる。`/passwd=` の `@` は空白に変えない
    - `host:port` と `host port` のどちらの書き方でもよい。`telnet://` と `ssh://` も使える
    - `/ssh` `/telnet` `/nossh` `/T=` `/auth=` `/keyfile=` `/ask4passwd` を受け付ける
    - シリアル: `/C=` `/BAUD=` `/SPEED=` `/CDATABIT` `/CPARITY` `/CSTOPBIT` `/CFLOWCTRL`
    - `/W=` `/timeout=` `/B` も受け付ける
  - 本当につながってから `result = 2`、失敗したら 1
  - `closett` や `unlink` のあともマクロは続く。次の `connect` で新しいウインドウを開く
- **ログ**
  - テキストのログ: エスケープシーケンスなしの UTF-8
  - バイナリのログ: 受信したバイトそのまま
  - `logopen`
    - ファイル名の `%Y%m%d` と `&h` `&p` `&u` を展開する
    - すでにログを取っているときに開こうとすると断る
  - `loginfo`: オプションの合計を返す。ログを取っていなければ -1
  - タイムスタンプの書式、`logwrite`、`logrotate` (世代数を指定しなければ上限なし)
  - `logautoclose`: マクロが終わったときにログを閉じる
- **ダイアログ**
  - `messagebox` `inputbox` `passwordbox` `yesnobox` `listbox` `statusbox` `filenamebox` `dirnamebox` `setdlgpos`
  - 引数の読み方、`\n` などの変換、どのボタンでマクロが止まるか
- **文字列**: `str*` 系の命令、`sprintf` (書式チェックと結果の番号、`%e` の指数は 2 けた、`%a` は 13 けた)、`int2str` / `str2int`、`code2str` / `str2code`、`tolower` / `toupper`
  - バイト単位で扱う。`strlen 'あ'` は 3
- **ファイル**
  - `file*` `folder*` `findfirst` などの命令、ハンドルの番号 (ファイル 16 個・フォルダ検索 8 個)
  - `filereadln` の改行の扱い、`filestrseek` の位置
- **パスワード**
  - `getpassword` / `setpassword` と、`*password2` (AES-256)
  - Windows 版が作ったパスワードファイルを読み書きできる
- **チェックサム**: `crc32` などのチェックサムの命令
- **ファイル転送**
  - 相対のファイル名は、本家と同じく `changedir` で決めたフォルダ (既定はダウンロード) が基準
  - TERATERM.INI の転送の設定を読む (FileDir、XMODEM の方式、ZMODEM のコマンド、時間切れ、自動受信など)
  - 転送が終わったあとに届いた文字は、画面とマクロに渡す
  - 転送中はキー入力を止める
  - シリアルの送信遅延は、転送中だけ止める
  - マクロを止めても転送は続く。中止は、転送中に出る進み具合の画面か「マクロ > ファイル転送を中止」で行う
- **Telnet**
  - CR NUL の扱いと BINARY オプションは本家と同じ
- **SSH**
  - `~.` で切断されないようにしている (`ssh -e none`)

## 3. Mac 向けに変えたところ (OS の違い)

本家と動きは違いますが、Mac ではこちらのほうが自然なので、わざとこうしています。

| 対象 | Windows 版 | Tera Term Mac |
|---|---|---|
| パス | `c:\work\a.txt`、`\\server\share` | Mac のパスを使う (`\` は `/` に読み替える。ドライブ名は捨てる)。`~` はホームフォルダ |
| `makepath` / `dirname` | 区切りは `\` | 区切りは `/` も使う |
| `findfirst` のワイルドカード | DOS の規則と 8.3 形式の短い名前 | Mac の規則 (大文字小文字は区別しない) |
| ファイルの共有ロック | 開いているファイルを別に開くと失敗することがある | 失敗しない |
| `filelock` | ほかのプロセスからも読めなくなる | 読めてしまう (`flock` を使う、使う側どうしの約束) |
| `filestat` のドライブ文字 | `C` など | `?` |
| `getfileattr` / `setfileattr` | Windows の属性 | 読み取り専用と隠しファイルを Mac のアクセス権・隠し属性に対応づける |
| `exec` | Windows の実行の仕組みで起動 | `/bin/sh -c` で起動。起動できなければ本家と同じく `result = -1` |
| `getspecialfolder` | Windows のフォルダ | Mac の近いフォルダ (デスクトップ、書類など) |
| `getdate` / `gettime` の `%Z` | Windows のタイムゾーン名 | `JST` など。`Asia/Tokyo` のような名前も使える |
| `setdate` / `settime` | 時計を変える | 何もしない (Mac ではアプリが時計を変えられない) |
| `getipv6addr` | Windows の基準で選んだアドレス | リンクローカル以外のアドレス |
| `sendkcode` | KEYBOARD.CNF のキーコード | よく使うキー (矢印・F キー・テンキーなど) だけ |
| `callmenu` | Tera Term のメニュー番号 | このアプリにある項目だけ。ほかは画面に案内を出す |
| `connect '/C=n'` | COM n | Mac のシリアルポートの一覧で n 番目 |
| `scpsend` / `scprecv` | TTSSH の中で転送 | SSH の接続を共有した `scp` コマンド |
| マクロファイル・パスワードファイル・送るファイルの文字コード (BOM なし) | Windows の文字コード (日本語なら Shift_JIS) | UTF-8 を先に試し、だめなら Shift_JIS |
| ログの既定のフォルダ | Tera Term のログフォルダ | `changedir` で決めたフォルダ。決めていなければ「書類」 |
| `beep` の種類 | Windows の音 | Mac の音 |
| `getver` | 本家の版 | 5.8 (移植した本家のソースの版) |

## 4. Mac にはないので動かないもの

| 命令 | 動き |
|---|---|
| `show` (マクロの小さいウインドウ) | 何もしない (マクロのウインドウはあるが、show での表示の切り替えはしない) |
| `loadkeymap` | 何もしない |
| `clearscreen 2` (TEK) | 何もしない |

## 5. わざと本家と変えた細かいところ

本家ではアプリが落ちるか、不具合になる場面です。

| 場面 | 本家 | Tera Term Mac |
|---|---|---|
| `-2147483648 / -1` | アプリが落ちる | 結果を返す |
| 511 バイトちょうどの `str2int`、知らない名前での `getspecialfolder` | アプリが落ちる | 普通に動く |
| `wait4all` | ほかのウインドウのマクロの受信を横取りしてしまう | 横取りしない |
| 配列の要素が 65536 個以上 | 番号が重なって別の要素を壊す | 正しく動く (上限は 6700 万個) |

## 6. 確かめ方

テストは次のコマンドで動かせます。

```sh
cd macos
swift build --build-tests && xcrun xctest .build/debug/TeraMacPackageTests.xctest   # 全テスト (172 件)
TERAMAC_UPSTREAM_REPORT=/tmp/r.txt xcrun xctest -XCTest TeraCoreTests.TTLUpstreamTests .build/debug/TeraMacPackageTests.xctest
# ↑ 本家の tests/*.ttl (62 本) を画面なしで動かし、エラーの一覧を /tmp/r.txt に書く
```

- 本家の `tests/*.ttl` で出るエラーは、どれも本家でもエラーになる (テスト用にわざと書いてある) 行だけです。例: `array.ttl` の `strarray[3`、`oneline-if.ttl` の「この行でエラーとなるのが正常」
- パスワードの暗号化は、本家の C のコードを実際にコンパイルして求めた値と一致することを確かめています
- ファイル転送は、このアプリどうしで送り合ったファイルが元と同じになることを確かめています
  - Windows 版や `sz` / `rz` を相手にしたテストはまだです
- 速さ: 100 万回のループが 5〜6 秒 (リリースビルド)
