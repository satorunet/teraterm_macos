VT100 の PF1-PF4 キー

初期設定 (KEYBOARD.CNF がないときの割り当て。IBMKEYB.CNF と同じ) では、VT100 の PF1-PF4 キーの機能は F1-F4 キーに割り当てられています。 Mac のキーボードでは、F1-F4 キーを押すときに fn キーも押す必要があることがあります (システム設定の「キーボード」で、F1、F2 などのキーを標準のファンクションキーとして使う設定にすると、fn は不要になります)。

割り当てを変えるには、キーボード設定ファイル KEYBOARD.CNF を書き換えてください。詳しくは、キーボード設定ファイルを読んでください。 以下は PF1-PF4 を F1-F4 キーに割り当てる例です。 

[VT numeric keypad]
PF1=59
PF2=60
PF3=61
PF4=62
; 59-62 は F1-F4 key のキーコード

[X function keys]
XF1=off
XF2=off
XF3=off
XF4=off
; キーコード 59-62 を二重使用しないようにするため XF1-XF4 を "off" にする。

テンキーの一番上の列 (Mac では clear、=、/、*) に割り当てたいときは、clear (Num Lock) が 325、/ が 309、* が 55 です。
