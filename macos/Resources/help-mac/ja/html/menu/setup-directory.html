Setup directory ([Setup] メニュー)

「Tera Term: 設定フォルダ」ダイアログが開き、Tera Term Mac が使っているファイルやフォルダの場所を一覧で表示します。 Tera Term 設定ファイル、キーボード設定ファイル、SSH known_hosts ファイル、設定フォルダ (HomeDir。~/Library/Application Support/Tera Term Mac)、アプリの実行ファイルの場所 (ExeDir)、ファイル転送のフォルダ、ログのフォルダ、ブロードキャストの履歴ファイルなどが表示されます。

行を右クリックすると、下記の操作を行うことができます。行をダブルクリックすると Finder で開きます。

Open file
ファイルをView log editorで指定したアプリケーションで開きます (指定がなければテキストエディット)。ファイルのときだけ選べます。
Open folder (with Finder)
Finder で開きます。ファイルのときは、そのファイルを選んだ状態でフォルダを開きます。
Send path to clipboard
パスをクリップボードにコピーします。
