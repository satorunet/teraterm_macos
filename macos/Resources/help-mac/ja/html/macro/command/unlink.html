unlink

現在のウインドウとマクロの間のリンクを断つ。 

unlink

解説

このコマンド以降、マクロは非リンク状態になり、そのウインドウを制御できなくなる。ウインドウはそのまま残り、マクロは動き続ける。
非リンク状態では、connect コマンドによって新しいウインドウを開き、マクロをそれにリンクさせることができる。

例

; ホストに接続する
connect 'host'

; リンクを断つ
unlink

; 新しいウインドウを開き、それにリンクして接続する
connect 'host2'
