scprecv

SCPプロトコルでファイルを受信する。 

scprecv <remote filename> [<local filename>]

解説

ファイル <remote filename> を SCP(Secure Copy Protocol) プロトコルで受信する。 SSH の接続を共有して、Mac の scp コマンドで転送する。SSH で接続しているときだけ使える。 ローカルファイル <local filename> を省略した場合は、ファイルはファイル転送フォルダ (changedir で決めたフォルダ、既定は「ダウンロード」) へコピーされる。 受信が終わるのを待たずに、次のコマンドを実行することができる。

例

connect '192.168.3.2:22 /ssh /auth=password /user=hoge /passwd=fuga'
wait '$'
scprecv 'bin/tool.sh'
scprecv 'sample.bin' '/Users/user/hoge.bin'
