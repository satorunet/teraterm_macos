Tera Term Mac は、Tera Term を macOS 用に移植したターミナルエミュレーター(通信プログラム)です。
Swift / AppKit で作り直しており、Apple Silicon と Intel の Mac で動きます。
TeraTerm Project とは関係のない個人の移植(非公式版)です。不具合や要望は本家ではなく、Tera Term Mac の連絡先へお願いします。

  • シリアルポート接続 (/dev/cu.*)
  • TCP/IP (telnet, SSH2) 接続。SSH は macOS の OpenSSH (ssh コマンド) を使います
  • ローカルシェル接続 (Mac のシェルを端末で使えます)
  • ログ再生
  • IPv6 対応
  • VT100 端末のエミュレーション (および、VT200, 300 の一部、xterm 互換の 256 色・TrueColor)
  • TEK4010 端末のエミュレーション
  • ファイル転送プロトコル (Kermit, XMODEM, YMODEM, ZMODEM, B-PLUS, Quick-VAN)
  • マクロ言語 (TTL) による自動運転。Windows 版のマクロがほぼそのまま動きます
  • TeraTerm Menu (メニューバーに常駐する接続先ランチャー)
  • Windows 版の設定ファイル (TERATERM.INI, ttpmenu.ini) の読み込み
  • Sparkle による自動アップデート
  • 文字種、文字幅は、本家 Tera Term と同じUnicode 18.0に準拠
  • UTF-8をはじめ多くの文字コードを使用可能
  • メッセージカタログ (本家の言語ファイルを使います)

このヘルプは本家 Tera Term のヘルプを元に、Mac 版に合わせて書き直したものです。 名前付きパイプ接続、CygTerm+、プラグイン (TTX) の追加など、Windows にしかない機能は Mac 版にはありません。
