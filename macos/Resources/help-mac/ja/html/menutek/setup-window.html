Window (TEK window [Setup] メニュー)

"TEK ウィンドウの設定" ダイアログボックス

設定できるのは、カラーエミュレーション、文字色、背景色です。 TEK window のタイトルは VT window と同じになります。 メニューバーの表示/非表示は、[Window] メニューの「メニューバーを開く/閉じる」で VT window と共通に切り替えます。 メニューバーを隠しているときは、control キーを押しながら左クリックするとメニューがポップアップします。

Color emulation
文字やグラフィックの色を指定するエスケープシーケンスを有効にします。このオプションを選択すると、選択しない場合に比べメモリ消費量が増加します。必要のない場合は選択しないでください。
Color
Text (文字色)
文字の色。クリックすると macOS のカラーパネルで色を選べます。
Background (背景色)
背景の色。クリックすると macOS のカラーパネルで色を選べます。
