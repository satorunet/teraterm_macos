Disabling the printing by the control sequence

You can enable the printing invoked by the control sequence. To do this, edit the PrinterCtrlSequence line in the [Tera Term] section of the setup file like the following: 

PrinterCtrlSequence=on

Default:
PrinterCtrlSequence=off
