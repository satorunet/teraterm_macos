[Edit] menu (TEK window)

Copy
Copies a selected portion of the screen to the clipboard as an image (Option+C).
Copy screen
Copies the screen to the clipboard as an image.
Paste
Sends text in the clipboard to the host (Option+V).
Right-clicking in the TEK window also pastes.
Paste<CR>
Sends text in the clipboard to the host, and then sends a new-line code (Option+R).
Clear screen
Erases the screen.

The TEK window menus are in the menu bar inside the window. Their shortcuts use the Option key.
