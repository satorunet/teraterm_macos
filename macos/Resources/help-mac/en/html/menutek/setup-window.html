Window (TEK window [Setup] menu)

"TEK window setup" dialog box

You can set color emulation, the text color and the background color. The TEK window uses the same title as the VT window. To show or hide the menu bar, use "Show Menu Bar / Hide Menu Bar" in the [Window] menu; it applies to VT and TEK windows alike. While the menu bar is hidden, control-click (left button) to pop up the menus.

Color emulation
Enables the emulation of colors for text and graphics. Note: Enabling this option consumes larger amount of memory.
Color
Text
Text color. Click to choose a color in the macOS Colors panel.
Background
Background color. Click to choose a color in the macOS Colors panel.
