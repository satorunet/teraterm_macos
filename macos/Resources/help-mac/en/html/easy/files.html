Send and receive files

Drag and drop (the easiest way)

  1. Drag the file from the Finder onto the terminal window.
  2. A dialog asks what to do.
    • When connected with SSH, choose "SCP" to copy the file to the server as it is. Use "dest:" to choose the folder on the server (empty means your home directory).
    • "Send File (Paste content of file)" sends the file's contents as if you typed them.
    • "Paste Filename" pastes the file name (path).
  3. Click "OK".

Send and receive with SCP (SSH only)

  1. In a window connected with SSH, choose [File] > [SSH SCP...].
  2. To send, choose the Mac file in the upper "From:" (you can also drag it onto the dialog), type the destination in "To:" and click "Send".
  3. To receive, type the server file name in the lower "From:", choose the Mac folder in "To:" and click "Receive".

Send the contents of a file

Useful for pouring a configuration file into a device.

  1. Choose [File] > [Send file...].
  2. Click the "..." button and choose the file.
  3. If the device is slow to receive, use "Delay type" to wait a little after each line.
  4. Click "OK" to start sending.


The [File] > [Send file...] dialog (the file name is an example)

XMODEM, ZMODEM and others

To write firmware to a device connected by serial, use XMODEM, YMODEM, ZMODEM, Kermit and so on under [File] > [Transfer]. Choose the protocol named in the device's manual and pick the file with "Send...".
