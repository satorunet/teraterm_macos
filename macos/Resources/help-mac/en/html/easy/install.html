Download and install

Tera Term Mac runs on macOS 11 Big Sur or later, on both Apple silicon and Intel Macs.

Download and install

  1. Open the Releases page.
  2. Click "TeraTermMac-(version).dmg" to download it.
  3. Double-click the downloaded .dmg file to open it.
  4. Drag the "Tera Term Mac" icon onto the "Applications" folder next to it.
  5. When the copy is done, you can eject the .dmg with the eject button in the Finder sidebar.

Tera Term Mac is notarized by Apple, so it opens without warnings.
If you start it directly from the .dmg or the Downloads folder, it asks "Move to the Applications folder?". Click "Move" and it copies itself to the Applications folder and starts again from there.

First launch

  1. Open "Tera Term Mac" from Launchpad or the Applications folder in the Finder.
  2. The host list (the TeraTerm Menu list editor) opens. It is empty at first.
  3. To connect right away, press ⌘N (File > New connection...). Continue with "Connect to a server with SSH".


The host list that opens at launch (two example hosts saved). See "Save the hosts you use often"

A Tera Term Mac icon also appears on the right side of the menu bar at the top of the screen. The app keeps running when you close all windows, and you can pick a host from that icon. To quit, press ⌘Q.

Updates

  • When a new version comes out, the app asks whether to install it. One click replaces it.
  • To check yourself, choose [Tera Term Mac] > [Check for Updates...].
