Tera Term Mac is a terminal emulator (communication program) ported from Tera Term to macOS.
It is rewritten in Swift / AppKit and runs on both Apple Silicon and Intel Macs.
It is an unofficial, personal port and is not affiliated with the TeraTerm Project. Please send bug reports and requests to Tera Term Mac, not to the TeraTerm Project.

It supports:

  • Serial port connections (/dev/cu.*).
  • TCP/IP (telnet, SSH2) connections. SSH uses macOS OpenSSH (the ssh command).
  • Local shell connections (use your Mac's shell in the terminal).
  • Log replaying.
  • IPv6 communication.
  • VT100 emulation and selected VT200/300 emulation, plus xterm-compatible 256 colors and TrueColor.
  • TEK4010 emulation.
  • File transfer protocols (Kermit, XMODEM, YMODEM, ZMODEM, B-PLUS and Quick-VAN).
  • Scripts using the "Tera Term Language" (TTL). Most Windows macros run as they are.
  • TeraTerm Menu (a connection launcher in the menu bar).
  • Importing Windows settings files (TERATERM.INI, ttpmenu.ini).
  • Automatic updates with Sparkle.
  • Character type and width conform to Unicode 18.0, the same as Tera Term.
  • Many character codes can be used, including UTF-8.
  • Message catalog (uses Tera Term's language files).

This help is based on the Tera Term help and has been rewritten for the Mac version. Windows-only features such as named pipe connections, CygTerm+ and add-on plugins (TTX) are not available in Tera Term Mac.
