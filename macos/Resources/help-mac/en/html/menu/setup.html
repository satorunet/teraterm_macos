[Setup] menu

Settings you confirm with OK in a setup window are saved automatically in the app's preferences and used again the next time the app starts.
Use [Save setup...] when you want to write them to a Tera Term setup file (TERATERM.INI).

The items from [Terminal...] to [Additional settings...] (except SSH and Proxy) all open the same "Tera Term: Additional settings" window. Only the tab shown first differs.

Terminal... (⌘,)
Opens the "Terminal" tab of Additional settings. Sets up the terminal emulation.
Window...
Opens the "Window" tab of Additional settings. Sets up the display.
Font...
Opens the "Font" tab of Additional settings.
Theme...
Opens the "Theme" tab of Additional settings.
Keyboard...
Opens the "Keyboard" tab of Additional settings.
Serial port...
Opens the "Serial port" tab of Additional settings. Disabled while a file transfer or a connection attempt is in progress.
Proxy...
Sets up the proxy.
SSH...
Sets up general SSH options.
SSH Authentication...
Sets up SSH authentication.
SSH Forwarding...
Sets up SSH port forwarding.
SSH Keygenerator...
Generates a key pair for SSH public key authentication.
TCP/IP...
Opens the "TCP/IP" tab of Additional settings.
General...
Opens the "General" tab of Additional settings.
Additional settings...
Opens Additional settings (starting with the "General" tab).
Save setup...
Saves the current setup to the Tera Term setup file.
Restore setup...
Restores the setup of Tera Term Mac from a setup file.
Setup directory...
Lists the locations of the setup files and other folders.
Load key map...
Restores the keyboard setup from a keyboard setup file.
