Setup directory ([Setup] menu)

Opens the "Tera Term: Setup directory" dialog, which lists the files and folders Tera Term Mac uses: the Tera Term setup file, the keyboard setup file, the SSH known_hosts file(s), the setup folder (HomeDir, ~/Library/Application Support/Tera Term Mac), the location of the app's executable (ExeDir), the file transfer folder, log folders, the broadcast history file and so on.

Right-click a row for the following operations. Double-clicking a row opens it in Finder.

Open file
Opens the file with the application set in View log editor (TextEdit if none is set). Available only for files.
Open folder (with Finder)
Opens it in Finder. For a file, the folder is opened with the file selected.
Send path to clipboard
Copies the path to the clipboard.
