Tera Term Mac Help

Tera Term Mac is a port of the Tera Term terminal emulator to macOS. It connects over SSH, telnet, serial ports and to a local shell, and runs TTL macros. It is an unofficial port and is not affiliated with the TeraTerm Project. This help is based on Tera Term's own help, adapted for the Mac.

Common tasks

  • New connection: ⌘N (File > New connection...)
  • Open a local shell: ⌘G
  • Copy / paste: ⌘C / ⌘V
  • Terminal settings: ⌘, (Setup > Terminal...)
  • Previous tab / next tab: ⌘{ / ⌘}
  • Run a macro: Control > Macro
  • Save settings: Setup > Save setup...
  • Open help: Help > Index
