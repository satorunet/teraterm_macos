How to open "TTL" files with Tera Term Mac

Tera Term Mac is registered as the app that opens files with the extension ".ttl". Double-click a .ttl file in the Finder and Tera Term Mac runs the macro.

If .ttl files open in another app, do the following:

  1. Select a .ttl file in the Finder and choose [File] > [Get Info] (⌘I).
  2. In "Open with", select Tera Term Mac.
  3. Click "Change All...".
