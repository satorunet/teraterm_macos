changedir

Changes the File transfer directory. 

changedir <path>

Remarks

Changes the File transfer directory to <path>.
The default file transfer directory is the Downloads folder (or FileDir in TERATERM.INI, if set). Use Mac paths (a drive letter such as 'c:' is ignored, '\' is treated as '/', and environment variables such as %HOME% can be used).

File name specified for the send communication commands (e.g. sendfile, kmtsend) and destination folder for receive commands (e.g. zmodemrecv) are based on the "File transfer directory."

If filename specified in communication command is a relative path, it is based on "File transfer directory". If the file name is an absolute path, it is not affected.

Note

The changedir command changes "File transfer directory."
The setdir command changes "current working directory for the macro."

The File transfer folder also affects log save location. If no default log folder is set in the settings, logs are saved in the File transfer folder (see logopen).

Example

changedir '/Users/user/Documents'
sendfile '/Users/user/source/code.dat' 1
