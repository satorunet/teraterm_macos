sendkcode

Sends the key code. 

sendkcode <key code> <repeat count>

Remarks

Performs a function defined for pressing a key or key combination.
The key or key combination is specified by its <key code> (the IBM PC keyboard key code, the same as in the keyboard setup file). The function is performed <repeat count> times.
Keys assigned in the keyboard setup file (KEYBOARD.CNF) send their assigned content. Otherwise only common keys (arrow keys, function keys, keypad keys etc.) can be sent. For key codes that cannot be sent, a "not supported" message is shown.

Usually the function means sending a character string to the host. The function can be defined in the keyboard setup file.
See Keyboard setup file.

The execution of macros using sendkcode in the [User keys] section of the keyboard setup file with <control flag> 2 is not possible.
The execution of menu commands using sendkcode in the [User keys] section of the keyboard setup file with <control flag> 3 is not supported.
Please use the callmenu command to execute menu commands.

Example

; Simulate pressing the down-arrow key three times.
; The key code of the down-arrow key is 336 for the IBM PC keyboard.
sendkcode 336 3
