Tera Term Mac is based on the following components.

Tera Term Mac

Tera Term Mac is a single app (Tera Term Mac.app). The features of the components below are all built into this app.

Tera Term

This is a terminal emulator for supporting telnet, serial and so on.
In Tera Term Mac, the terminal emulator itself is rewritten in Swift / AppKit. The TTL macro engine (ttpmacro) and the file transfer protocols are ported from Tera Term's source code.

TTProxy

A module that supports proxy connections (HTTP / SOCKS4 / SOCKS4a / SOCKS5 / TELNET). It is built into Tera Term Mac.

TeraTerm Menu

A launcher that supports automatic login. It is built into Tera Term Mac and stays in the menu bar. Passwords are stored in the macOS Keychain.
